# 🚀 RADAR DA VOZ — Transformação em Startup de Economia de Talentos

## **VISÃO EXECUTIVA**

O **Radar da Voz** evoluirá de um analisador de voz isolado para uma **plataforma de marketplace de talentos multidimensional** que conecta descoberta, análise e monetização de profissionais criativos em múltiplos canais.

---

## **PROBLEMA QUE RESOLVE**

### 🎯 **Para Artistas:**
- Artistas desconhecidos não têm como ser descobertos por produtoras, TV, marcas
- Criadores não conseguem monetizar seus talentos
- Acesso limitado a oportunidades profissionais

### 🎯 **Para Produtoras/Agências:**
- Descoberta manual é cara, lenta e ineficiente
- Não há curadoria inteligente de talentos
- Falta acesso a banco estruturado de candidatos

### 🎯 **Para Empresas/Marcas:**
- Publicidade tradicional é cara
- Influenciadores cobram alto
- Não conseguem conectar com talentos regionais/micro-influenciadores

### 🎯 **Para Blogueiros/Influenciadores:**
- Dificuldade em monetizar sem apenas publicidade tradicional
- Sem acesso a oportunidades comerciais estruturadas

## **PLAYERS NA PLATAFORMA (6 TIPOS DE USUÁRIO)**

### **1️⃣ ARTISTAS / TALENTOS**
**O que ganham:**
- Visibilidade para produtoras, TV, empresas
- Oportunidades de trabalho (backing vocal, bandas, comerciais)
- Portfólio digital com análise inteligente
- Monetização de skills

**Como usam:**
```
Cadastro → Grava voz/vídeo → Análise automática → Fica no banco
→ Produtoras/empresas encontram → Recebem propostas
```

---

### **2️⃣ PRODUTORAS DE MÚSICA/ÁUDIO**
**O que ganham:**
- Banco curado de cantores, instrumentistas
- Análise técnica de voz/performance
- Comparador de casting (2-6 talentos lado-a-lado)
- Histórico de contratações

**Como usam:**
```
Login → Exploram banco (filtro por região, estilo, nível)
→ Comparam talentos → Contatam diretamente → Contratam
→ Deixam feedback (melhora ranking do talento)
```

**Modelo de negócio:**
- Assinatura premium (R$ 99-299/mês) para acesso ilimitado
- Créditos para contato direto (R$ 10/contato)

---

### **3️⃣ BANDAS / MÚSICOS PROFISSIONAIS**
**O que ganham:**
- Encontrar músicos que precisam (guitarrista, baixista, baterista)
- Substituições rápidas quando alguém sai
- Rede de profissionais confiáveis

**Como usam:**
```
Postam "procuramos guitarrista rock SP" → Talentos se candidatam
→ Comparam → Entrevistam → Contratam
```

**Modelo de negócio:**
- Postagem de vaga (R$ 49/mês) ou créditos (R$ 5 por vaga)

---

### **4️⃣ EMPRESAS / MARCAS**
**O que ganham:**
- Anúncio de baixo custo (pagam apenas pela produção do vídeo)
- Alcance regional através de influenciadores
- Autenticidade (não é anúncio corporativo genérico)
- Dados de performance do anúncio

**Como usam:**
```
Criam briefing: "Produto: Refrigerante | Público: 18-35 | Região: SP"
→ Influenciadores/talentos veem → Criam vídeo → Empresa aprova
→ Publica → Nós medimos alcance/engajamento
```

**Modelo de negócio:**
- Comissão sobre produção: **Empresa paga R$ 500-2000 ao influenciador**
- **Nós ficamos 15-20%** da transação

---

### **5️⃣ INFLUENCIADORES / MICRO-INFLUENCIADORES**
**O que ganham:**
- Monetização além de publicidade tradicional
- Campanhas comerciais para marcas
- Representação local (viram agentes)
- Comissão sobre vendas locais

**Como usam:**
```
Se cadastram como influenciador → Veem campanhas abertas
→ Criam vídeo + postam → Ganham R$ 200-1000 por campanha
OU
Se cadastram como representante local → Empresas procuram eles
→ Promovem marca na região → Ganham comissão sobre vendas
```

**Modelo de negócio:**
- Nós ficamos 20-30% da transação com influenciador

---

### **6️⃣ TV / RÁDIO / PRODUTORAS AUDIOVISUAIS**
**O que ganham:**
- Descoberta rápida de artistas para programas
- Backup vocal de qualidade
- Talentos regionais para transmissões ao vivo
- Pipeline estruturado de artistas

**Como usam:**
```
Postam "procuramos cantor sertanejo MG para programa" → Talentos se candidatam
→ Assistem vídeos → Entrevistam os 3 melhores
→ Contratam para gravação/apresentação
```

**Modelo de negócio:**
- Assinatura (R$ 299-999/mês) + taxa por contrato firmado

## **MELHORIAS IMEDIATAS NA PLATAFORMA**

### **INTERFACE (UX/UI)**
1. ✅ **Sistema de Login** (Artista, Produtora, Empresa, Influencer)
2. ✅ **Perfis diferenciados** por tipo de usuário
3. ✅ **Dashboard personalizado** (o que cada um vê é diferente)
4. ✅ **Histórico de interações** (quem contatou quem, quando)
5. ✅ **Notificações** (nova proposta, mensagem, feedback)

### **FUNCIONALIDADES**
1. ✅ **Upload de vídeo** (não só áudio)
2. ✅ **Análise de vídeo** (carisma, naturalidade, técnica)
3. ✅ **Sistema de mensagens** (chat entre usuários)
4. ✅ **Agendamento de chamadas** (Zoom, Meet integrado)
5. ✅ **Portfólio/galeria** (múltiplos vídeos e audições por artista)
6. ✅ **Sistema de avaliação** (feedback das produtoras)
7. ✅ **Tags/especialidades** (sertanejo, axé, rock, backing vocal, etc)
8. ✅ **Geolocalização** (mostrar talentos próximos)

### **BACKEND**
1. ✅ **Banco de dados real** (PostgreSQL/Supabase)
2. ✅ **API estruturada** (REST/GraphQL)
3. ✅ **Autenticação** (JWT, OAuth Google/LinkedIn)
4. ✅ **Armazenamento de mídia** (S3, Cloudinary)
5. ✅ **Sistema de pagamentos** (Stripe, Pix)
6. ✅ **Analytics** (quais talentos foram mais vistos, etc)

### **SEGURANÇA**
1. ✅ **Verificação de identidade** (talentos reais)
2. ✅ **Contrato digital** (E-signature para contratações)
3. ✅ **Proteção de direitos autorais** (áudios/vídeos)
4. ✅ **Disputas e arbitragem** (mediação de conflitos)
